AutismBench

An independent benchmark of pattern-spotting, rule-following and exact attention to detail. It scores language models on hard, code-graded tasks, then reports how smart, how fast, and how expensive each one is.

These are sample numbers from pretend models, shown so you can see the layout. Run the benchmark with real models to replace them.
Scoring is fully automatic and every raw reply is saved. See METHODOLOGY.md in the repository for the full rules.
